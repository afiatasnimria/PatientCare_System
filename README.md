
# 🏥 PatientCare System
### A Healthcare Management System – UI/UX Design Prototype

**PatientCare System** is a healthcare management system prototype designed primarily using Figma as part of a System Analysis and Design (SAD) project. The project focuses on designing an intuitive and user-friendly healthcare platform that simplifies interactions between patients and healthcare service providers.

The prototype demonstrates the system's interface, navigation, user workflows, and core healthcare management functionalities.

---

## ✨ Key Features

- **User Authentication** – Login and registration interface.
- **Patient Dashboard** – Centralized patient information and activities.
- **Appointment Management** – Appointment booking and scheduling interface.
- **Doctor Management** – Doctor profiles and healthcare service information.
- **Medical Records** – Interface for managing patient health records.
- **Prescription Management** – Digital prescription interface.
- **Healthcare Navigation** – Structured navigation for easy access to services.
- **User-Friendly Interface** – Clean and intuitive design for better user experience.

## 🎨 Design & Tools

- **Figma** – UI/UX Design and Interactive Prototyping
- **System Analysis and Design** – Requirement analysis and system modeling
- **User Flow Design** – Navigation and workflow planning
- **Wireframing** – Interface structure and layout planning
